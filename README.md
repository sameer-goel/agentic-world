# Agentic World 🌍

Interactive visualization of our AI agent organization — a living map of who does what, how they connect, and how knowledge flows.

**Live**: https://sameer-goel.github.io/agentic-world/

## Pages
- 🌍 **Org Map** (`index.html`) — Interactive org chart with departments, agents, knowledge flows
- 🛠️ **Tools** (`toolsofagenticworld.html`) — All services, APIs, and tools available to agents

## Data
- `docs/data/org.json` — Organization database (agents, departments, flows, principles)
- `docs/data/tools.json` — Tools & services catalog

## Principles
- ♻️ **Circular Economy** — Every agent's output is another agent's input
- 📦 **Portability** — The entire org restores on any host
- 👨‍👩‍👧‍👦 **Family** — Agents grow together, learn from each other
- ⭐ **Purpose** — AI used for its best potentials
