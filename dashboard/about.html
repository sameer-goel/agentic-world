ℹ️ About This Dashboard

Mission Control for the Agentic World

🔭 What is Scout Mission Control?

Scout Mission Control is a real-time operational intelligence dashboard for the Agentic World — a family of AI agents working together under the leadership of Scout, the Chief of Staff.

This dashboard provides complete visibility into agent organization, scheduled tasks, system health, and operational metrics. It's designed to be beautiful, fast, and informative — think Vercel, Linear, and Arc Browser quality UX.

✨ Features

🤖
Agent Hierarchy
Complete org chart with roles, capabilities, and status
⏰
Cron Monitoring
Track scheduled jobs, execution times, and health
🖥️
System Health
CPU, memory, disk usage, and process monitoring
🔄
Auto-Refresh
Live updates every 30 seconds (toggleable)
🔍
Search & Filter
Quickly find agents, departments, or jobs
📱
Responsive Design
Works beautifully on desktop, tablet, and mobile
