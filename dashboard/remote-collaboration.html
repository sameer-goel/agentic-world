🔭 Remote Collaboration with OpenClaw

Multi-channel AI agent architecture for autonomous R&D operations. Control Scout from anywhere via WhatsApp, Discord, Telegram, or web.

🏗️ Architecture Overview

OpenClaw is a self-hosted gateway that bridges messaging apps to AI agents. You send a message via WhatsApp, Discord, or Telegram — the Gateway routes it to Scout or a specialized sub-agent, executes tools, and sends the response back to your channel.

📱 WhatsApp Message → 🌐 Gateway → 🤖 Agent Session → 🔧 Tools & APIs → 💬 Response
Key Components:
  • Gateway Core — Single process managing all channels, sessions, and routing
  • Multi-Channel Router — WhatsApp, Discord, Telegram, Slack, Signal, iMessage, WebChat
  • Session Manager — Isolated sessions per sender/workspace with memory persistence
  • Agent Team — Scout (main), Sherlock (research), Infra (monitoring), Sentinel (security), Phoenix (DR)
  • Tool Integration — Browser automation, GitHub, email, cron jobs, voice, web search
  • Storage Layer — MEMORY.md (long-term), daily logs, config, git repos, skills cache

🔄 Collaboration Patterns

1. Direct Chat (Synchronous)

Send a message to Scout via WhatsApp → Immediate response with web search, analysis, or action.

You: "What's the latest on agentic AI funding?" Scout: [Searches + synthesizes] "Found 3 new rounds this week... Here's the pattern..."

2. Async Cron Tasks (Fire & Forget)

Scheduled jobs run every 30min-12h, deliver results to your channel.

  • Smart Intel Pipeline (30min) — Auto-publishes research
  • Email Monitor (2h) — Urgent emails only
  • Infra Monitor (3h) — Disk/health alerts
  • Security Audit (6h) — Vulnerability checks

3. Sub-Agent Delegation

Scout spawns specialized agents for complex work, reports findings back.

Scout spawns Sherlock → "Research 'agentic AI vs traditional automation'" Sherlock runs 20min autonomously → Reports conclusions Scout synthesizes + sends summary to WhatsApp

4. Multi-Channel Coordination

Different channels for different purposes. Scout intelligently routes based on sender.

  • WhatsApp → Urgent, interactive, real-time
  • Discord → Team discussions, code reviews, long-form
  • Telegram → Alerts, monitoring, automated briefings
  • WebChat → Browser dashboard, full history

💡 Best Practices

Communication Style

  • Be specific: "Research X" vs "do research"
  • Use channels appropriately: WhatsApp for urgent, Discord for discussion
  • Include context: Scout works better with background
  • Request format: "Find 5 companies doing X and why they matter"

Cost Optimization

  • Batch requests: Combine multiple asks into one message
  • Use caveman mode: Terse responses cut tokens by 75%
  • Archive memory: Monthly rollups of daily logs to MEMORY.md
  • Monitor cron spend: Ensure all crons use Haiku, not Opus

Operational Stability

  • Check disk health: Infra Chief monitors every 3h, but manually audit quarterly
  • Backup reminders: Phoenix runs every 12h, verify Google Drive has recent backups
  • Git discipline: Push frequently to avoid data loss
  • Secret hygiene: Never paste API keys in chat — reference by name
